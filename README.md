# 공원 업무 수첩

Windows 10/11에서 폐쇄망 업무 도구를 한곳에 모으기 위한 **비공식 초기 시제품**입니다. 국립공원공단의 공식 제품이나 연동 승인을 받은 서비스가 아닙니다.

## 구현한 기능

- 오늘의 업무: 남은 일정, 메모, 처리할 전화, 자주 가는 폴더 요약
- 메모 작성·검색·삭제
- 날짜순 일정 등록·완료 처리·삭제 및 앱 실행 중 OS 알림
- 전화메모 작성·검색·처리 상태 관리
- 폴더 선택·열기·바로가기 제거
- 데스크톱에서 JSON 백업·복원. 복원 전 현재 데이터를 자동 보관

월간 달력, 반복 일정, 법령 검색, ERP, 회계·서무, 순찰·당직·민원 기록, 변환기 등은 **아직 구현하지 않았습니다**. 앱의 ‘확장 계획’과 [설계 제안](docs/architecture.md)을 참고하세요.

## 개발

Node.js 24와 npm을 기준으로 합니다. 기존 체크아웃에서 작업하며 별도 Git worktree는 필요하지 않습니다.

```sh
npm ci
npm test
npm run build
npm run desktop
```

`npm run dev`는 브라우저용 화면 개발 모드입니다. 데스크톱 IPC가 없으면 별도 localStorage를 사용하며, OS 알림·폴더 선택·백업은 지원하지 않습니다. 브라우저와 데스크톱 데이터는 자동 공유되지 않습니다. 개발 서버에는 외부 통신용 코드가 없지만 Vite 개발 도구는 로컬 연결을 사용합니다.

## Windows 설치 파일

인터넷 사용이 가능한 Windows 빌드 PC에서:

```powershell
npm ci
npm test
npm run package:win
```

`release/`의 NSIS 설치 파일을 검사·승인한 뒤 폐쇄망으로 반입합니다. 최초 빌드는 npm 패키지와 Electron/NSIS 도구 다운로드가 필요합니다. 설치된 앱은 CDN·폰트 다운로드·자동 업데이트·외부 API 없이 로컬 자산으로 실행됩니다. Windows 설치 및 알림의 실제 검증은 Windows PC에서 해야 합니다. 현재 코드 서명 인증서는 설정되어 있지 않습니다.

## 저장과 주의사항

Electron 사용자 데이터 폴더의 `workdesk.json`에 저장합니다. Windows에서는 통상 `%APPDATA%/park-workdesk/`이며 설치 환경에 따라 경로를 확인하세요. JSON은 암호화되지 않습니다. 민감한 민원·개인정보나 실제 기관 업무자료를 넣기 전에 기관 보안·개인정보 검토, 접근 통제와 저장 암호화가 필요합니다. 개발 중에는 가상 자료를 사용하세요.

알림은 앱이 켜져 있고 PC가 깨어 있을 때 15초 간격으로 확인합니다. 종료·절전 중 알림과 1분 이상 지난 알림은 재생하지 않습니다. 동일 시각 알림은 실행 세션에서 중복 표시하지 않으며 재실행 시 1분 이내 알림은 다시 표시될 수 있습니다. Windows 알림 허용 설정을 확인하세요. 창을 닫으면 앱이 종료됩니다.

백업 파일에는 모든 메모·일정·전화번호·폴더 경로가 포함됩니다. 보안이 승인된 저장 위치에 보관하세요. 복원 전 자동 보관 파일은 동일한 사용자 데이터 폴더에 생성됩니다. 폴더 바로가기는 해당 PC의 경로이므로 다른 PC로 복원하면 다시 등록해야 할 수 있습니다. 현재는 파일 바로가기와 실행 파일 실행을 지원하지 않습니다.

## 검증

`npm test`는 저장·읽기, 잘못된 백업 거부, 기존 데이터 보존, 알림 대상 판별을 검사합니다. `npm run test:desktop`은 실제 Electron을 임시 프로필로 실행하여 메모 저장·재읽기, 일정 완료, 전화 처리, 백업·복원과 폴더 등록을 확인합니다. 파일 선택과 확인 대화상자만 테스트에서 대체하며 OS 알림 표시·탐색기 실행·Windows 설치는 별도로 확인해야 합니다. Linux 클라우드 테스트는 GUI 대신 headless 모드를 쓰며 해당 테스트 프로세스에만 `--no-sandbox`를 적용합니다. 실제 앱의 sandbox 설정은 유지합니다.

클라우드에서는 다음 캐시 및 프록시 설정으로 설치를 검증했습니다. 프록시 인증 값은 저장하지 않으며 기존 환경 설정을 이용합니다.

```sh
export npm_config_cache=/workspace/.cache/npm
export electron_config_cache=/workspace/.cache/electron
export ELECTRON_GET_USE_PROXY=1
npm ci
npm test
npm run test:desktop
```
