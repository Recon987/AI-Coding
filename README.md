# 공원 업무 수첩 · v0.6.1

국립공원 현장과 사무실의 업무를 연결하는 **Windows 10/11용 개인 업무 기록 시제품**입니다. 순찰에서 확인한 사항을 인수인계로 넘기고, 제출 기한과 일정을 함께 관리합니다. 공식 기관 제품·결재·근태·긴급 대응 시스템은 아닙니다.

## 개발 협업 체계

Codex·Gemini·Claude가 역할을 나눠 과제 카드 단위로 작업합니다. 현황은 `npm run board`, 절차는 [에이전트 운영 체계](docs/orchestration/README.md)를 확인하세요.

## 순찰 종류·담당구역·단속 건 집계 (`TASK-PATROL-02`)

순찰 기록에 **순찰 종류**(안전·자원보전·단속·산불 감시·시설 점검·사고 대응·일반)와 **담당구역 번호**를 남길 수 있습니다. **단속·확인 건**은 유형(예: 샛길·출입금지구역 출입, 지정 장소 외 취사), 건수, 조치(계도·과태료 부과·기타), 메모, 위치(위도·경도)를 건별로 기록합니다. 유형은 기본 제안 목록에서 고르거나 새로 입력할 수 있고, 한 번 쓴 유형은 다음부터 제안됩니다. 현장 순찰 화면 위쪽 **단속·확인 집계**에서 이번 주·이번 달·최근 30일의 유형별 건수와 조치를 합산합니다. 모두 선택 항목이며 기존 순찰 기록은 그대로 읽힙니다. 과태료 금액과 위반자 인적사항은 저장하지 않습니다.

## 자료 손상 복구 (`TASK-DATA-01`)

저장할 때마다 디스크에 확정한 뒤 파일을 교체하고, 같은 내용의 마지막 정상본(`workdesk.json.last-good`)을 함께 보관합니다. 업무 자료를 읽지 못하면 손상된 파일을 지우지 않고 `workdesk.json.corrupt-<시각>.json`으로 보관한 뒤 **마지막 정상본으로 시작 / 백업 파일에서 복원 / 종료** 중에서 고르게 합니다.

## v0.6.1 세 분야 협의 개선 (`TASK-UX-03`)

UX·정보 구조, 시각 디자인, 데스크톱 품질 담당 에이전트가 같은 가상 자료와 실제 화면을 검토하고 서로의 제안을 협의했습니다. 모든 기록이 비어 있을 때는 **일정 등록·전화메모 작성·근무현황판 준비** 세 행동을 보여줍니다. 기록이나 조직 정보가 한 건이라도 있으면 기존 브리핑을 유지합니다.

읽기용 날짜와 TXT 출력은 현지 날짜·24시간제로 통일했습니다. 달력은 제목 공간을 넓히고 유형 아이콘·전체 제목 안내·선택 날짜 목록을 제공합니다. 키보드로 날짜를 선택해 전체 기록을 확인할 수 있습니다. [협의·교차 검토와 전후 화면](docs/review-rounds/TASK-UX-03.md)을 확인하세요.

## v0.6 트레이 상주·절전 복귀 알림 (`TASK-TRAY-01`)

**앱 안내 → 트레이와 알림 → 창을 닫아도 시스템 트레이에 유지**를 켜면 닫기 버튼은 창을 숨깁니다. 기본값은 꺼짐이며 Windows 자동 시작은 제공하지 않습니다. 트레이의 **열기/종료**, 아이콘 클릭, 앱 다시 실행으로 창을 다시 열 수 있습니다. 종료 시 미저장 내용이 있으면 기본 선택은 계속 작성입니다.

실행 중 15초마다 최근 1분의 알림을 점검하고, 절전 복귀 때만 지난 24시간의 미완료 일정·인계·제출 알림을 보충합니다. 4건 이상은 한 알림으로 묶습니다. 표시 요청 이력은 PC에 보관해 재실행 후에도 같은 회차를 다시 요청하지 않으며, Windows 알림 허용·집중 지원에 따라 실제 표시는 달라질 수 있습니다. 오래전에 시작한 반복 일정이 400회 이후 조회되지 않던 문제도 수정했습니다.

PC 설정(`desktop-settings.json`)과 알림 이력(`notification-receipts.json`)은 업무 자료와 별도이며 업무 JSON 백업·복원 대상에 포함되지 않습니다. 기존 자료 형식은 v3입니다.

## v0.5 월간 달력 공휴일·반복 일정 (`TASK-CALENDAR-01`)

- **오프라인 법정공휴일·대체공휴일 표시**: 외부 API 호출 없이 양력 법정공휴일(신정, 삼일절, 어린이날, 현충일, 광복절, 개천절, 한글날, 성탄절)과 2025~2035년 음력 법정공휴일(설날 연휴, 부처님오신날, 추석 연휴) 및 주말·공휴일 중복에 따른 대체공휴일을 자동 계산해 월간 달력과 업무 브리핑(화면·TXT)에 표시합니다.
- **반복 일정 파생 표시**: 개인 일정 등록·수정 시 `반복 없음 | 매일 | 매주 | 매월 | 매년` 주기와 선택적 `반복 종료일(YYYY-MM-DD)`을 설정할 수 있습니다. 원본 일정 1건만 저장하고 달력·브리핑·알림에서 회차를 파생 계산하며, 월말(예: 1월 31일 → 2월 28일/29일)과 윤년(2월 29일 → 평년 2월 28일) 경계를 안전하게 보정합니다.
- **무손실 하위 호환**: 저장 형식은 `v3`을 유지하며, 기존 `v1`/`v2`/`v3` 일정(반복 속성이 없는 기록)을 수정 없이 그대로 읽고 저장합니다.

## v0.4 사무소 현황판

**사무소 현황 → 조직 관리 → 직원 관리 → 거점 관리**에서 기준 정보를 등록한 뒤, **근무현황**에서 직원별 근무를 입력합니다. 일별 현황과 주간표, 조직·직원 검색, 휴무·당직·미등록 필터를 제공합니다. 기본 근무(사무소/휴무/연가/출장/거점)와 당직(주간/숙직)은 함께 기록할 수 있습니다. 미등록 상태를 근무로 추정하지 않습니다.

**파일 반입**에서 UTF-8 CSV를 선택하거나 붙여넣고, 추가·수정·유지 내역을 미리 본 뒤 적용합니다. 기존 직원번호와 조직·거점 코드로 연결하며 오류가 있으면 전체 반입을 거부합니다. 최대 2MB/10,000행입니다. 전출 직원은 비활성으로 전환하면 과거 근무 기록을 보존할 수 있습니다. 전체 JSON 백업에 이 자료도 포함됩니다.

ERP의 실제 열·근무 코드는 아직 미확인입니다. 현재 표준 CSV를 지원하며 ERP 자동 조회·공용 서버 동기화·자동 근무 편성은 제공하지 않습니다. [ERP 매핑 설계 및 CSV 양식](docs/erp-integration.md)을 확인하세요.

## 사용 흐름 개선

독립 검토 두 차례를 거쳐 상단 안내와 집계를 압축하고 기한 경과·오늘 마감 필터, 날짜별 업무/순찰/일정, 회신할 전화와 메모를 첫 화면에 배치했습니다. 조회와 작성을 분리해 추가/수정은 공통 편집창으로 열고, 목록의 긴 원문은 펼쳐 읽습니다. 미저장 변경·닫기 확인·저장 실패 시 초안 보존을 제공하며, 선택 좌표는 펼쳐 입력합니다. Ctrl+K 또는 /로 원래 화면 위에 통합 검색을 열고 Esc로 닫습니다. 검색으로 작성 중 내용이 지워지지 않습니다. 앱 안내는 보관 위치·백업·알림 사용법으로 정리했습니다.

## 이번 버전에서 사용할 수 있는 기능

- **사무소 현황**: 조직·직원·거점 등록, 일별/주간 근무표와 휴무·당직 현황, CSV 미리보기 반입.
- **업무 브리핑**: 미완료 인계·제출, 지난 기한, 미처리 전화와 날짜별 순찰·일정·공휴일 확인. 선택 날짜의 브리핑을 TXT로 내보내기.
- **현장 좌표**: 순찰 등록·수정 시 DD↔DMS 오프라인 변환, 범위 검사, 좌표 검색, 브리핑 화면·TXT 표출.
- **현장 순찰**: 구간·기록자·확인 등급·확인 사항·현장 조치 등록, 검색, 수정, 삭제.
- **인수인계**: 순찰 기록에서 후속 조치로 연결. 담당자·마감일·우선순위·완료 일시 관리. 같은 순찰의 미완료 조치는 다시 열어 중복 생성을 방지.
- **제출 기한**: 서류명·담당자·제출처·마감일, 1일 전/1시간 전/마감 시각 알림과 제출 완료 기록.
- **월간 일정**: 개인 일정(단일·반복)·순찰·인계·제출 기한과 오프라인 법정공휴일·대체공휴일을 함께 표시. 원본 변경이 바로 반영되며 별도 복제 일정은 생성하지 않음.
- **전화메모·업무 메모**: 등록, 검색, 수정, 삭제와 전화 처리 상태.
- **통합 검색**, 폴더 바로가기, 전체 JSON 백업·복원.

법령 반입·검색, ERP 자동 연동·공용 서버, 거점표·당직표 자동 편성, 예산·급량비·물품 장부, EPSG 간 투영좌표 변환 및 반복 일정 회차별 개별 예외 처리는 후속 단계입니다.

## v0.3 좌표 입력하기

1. **현장 순찰**에서 기록을 등록하거나 수정하고, **현장 좌표 → 좌표 입력 형식**을 선택합니다.
2. DD는 부호 있는 위도·경도를 입력합니다. 예: `37.5`, `127.25` → `N 37° 30′ 0″, E 127° 15′ 0″`.
3. DMS는 위도·경도의 도·분·초와 방향을 모두 입력합니다. 남위 S·서경 W는 음수 DD로 변환됩니다. 반대 형식은 입력 즉시 표시됩니다.
4. **순찰 저장/변경 저장**을 누릅니다. 순찰 목록·통합 검색에서 숫자 또는 표시된 DMS 문자열로 찾고, **업무 브리핑**에서 해당 날짜의 좌표를 확인하거나 TXT로 내보냅니다.

좌표는 선택 사항입니다. 일부만 입력했거나 잘못된 범위이면 저장할 수 없습니다. **좌표 지우기 → 변경 저장**으로 제거합니다. 위도 ±90°, 경도 ±180°, 분 0~59, 초 0 이상 60 미만이며 경계 90°/180°에서는 분·초가 0이어야 합니다. 도·분은 정수입니다. 소수점은 점(.)을 사용합니다.

DD 원본만 저장하고 DMS 초는 소수 6자리까지 계산합니다(자리올림 포함, 왕복 오차 최대 약 1.4e-10도). 입력 형식 전환만으로 저장 원본을 바꾸지 않습니다. 원자료의 좌표계를 그대로 유지하는 **각도 표기 변환**이며, WGS84 등 좌표계 판별·변환, 미터 단위 투영좌표, 지도나 GPS 수집 기능은 없습니다.

기존 v0.2 순찰은 좌표 없이 그대로 읽습니다. 현재 앱은 0.6.1 / 저장 형식 v3이며 기존 자료는 자동 백업 후 전환합니다. 좌표 누락/`null`과 실제 `0도`는 구분됩니다.

## Windows에서 확인하기

Windows 소스·패키징된 앱 검증 완료: [v0.6.1 설치형·portable 다운로드](https://github.com/Recon987/AI-Coding/actions/runs/38844487365/artifacts/12023060736). GitHub 로그인 필요, 보관 14일.

회사 네트워크에서 개발용 패키지를 설치할 필요가 없도록 [Windows 빌드](https://github.com/Recon987/AI-Coding/actions/workflows/windows-build.yml)를 준비했습니다.

1. GitHub에 로그인하고 **성공 표시가 있는 최신 빌드 실행**을 엽니다. 성공 기록이 없다면 아직 실행 파일이 준비되지 않은 상태입니다.
2. 실행 페이지 하단 **Artifacts → park-workdesk-windows-숫자**를 내려받고 압축을 풉니다. 보관 기간은 14일입니다.
3. 설치하려면 이름에 `Setup`이 있는 EXE, 설치 없이 시험하려면 나머지 portable EXE를 사용합니다. 저장 데이터는 두 방식 모두 앱의 사용자 데이터 폴더에 남습니다. USB에 EXE만 복사해도 사용자 데이터가 함께 이동하지 않습니다.
4. 동일 묶음의 `SHA256SUMS.txt`와 `Get-FileHash <파일명> -Algorithm SHA256` 결과를 대조할 수 있습니다.

실행 PC에 Node.js나 Python 설치는 필요하지 않습니다. 인터넷 PC에서 파일을 받은 후 기관 반입 절차를 따르세요. 코드 서명은 아직 설정하지 않았습니다. 기관 PC에서 실행이 차단되면 승인 절차를 확인하세요. 자동 빌드는 소스 실행과 패키징된 앱의 업무 흐름을 각각 검사합니다. 기관 실기기 승인 검증은 별개입니다.

## 개발자 실행

Node.js 24와 npm 기준입니다. 기존 체크아웃에서 작업하며 별도 Git worktree는 필요하지 않습니다.

```sh
npm ci
npm test
npm run desktop
```

`npm run dev`는 브라우저 개발 모드입니다. 별도 localStorage를 사용하며 OS 알림·폴더 열기·백업·TXT 내보내기는 데스크톱 앱에서만 제공됩니다. 브라우저와 데스크톱 데이터는 자동 공유되지 않습니다.

직접 Windows 패키지를 빌드하려면 인터넷이 되는 Windows PC에서 `npm run package:win`을 실행하세요. `release/`에 NSIS 설치 파일과 portable EXE를 생성합니다. 첫 빌드에는 npm·Electron·NSIS 도구 다운로드가 필요합니다. 설치된 앱의 화면과 기능은 외부 CDN, 자동 업데이트, API 호출 없이 동작합니다.

## 저장·기존 자료 보존

Electron 사용자 데이터 폴더의 `workdesk.json`에 저장합니다. Windows에서는 통상 `%APPDATA%/park-workdesk/`입니다. v1/v2 자료는 첫 실행에서 원본 `workdesk.json.v1-backup.json` 또는 `.v2-backup.json`을 보관한 뒤 v3 형식으로 전환합니다. 기존 메모·일정·전화·바로가기·순찰·인계·좌표는 유지됩니다. 이전 앱은 v3를 읽지 못하므로 이전 앱으로 되돌릴 때는 원본 백업을 별도로 보존하세요.

백업에는 조직·직원·거점·근무표·순찰·인계·제출·반복 일정을 포함한 모든 기록과 폴더 경로가 들어갑니다. 복원은 현재 자료를 교체하며 교체 전 자동 보관 파일을 남깁니다. 연결이 끊긴 순찰 ID 등 잘못된 자료는 복원 전에 거부합니다. 폴더 연결은 PC별 경로를 사용합니다. 저장·반입 한도는 JSON 20MB, 각 기록 종류 10,000건입니다.

**저장 파일·백업·브리핑은 현재 암호화되지 않습니다. 가상 자료로 시험하세요.** 민원인 정보 등 실제 업무자료를 넣기 전 접근 통제·암호화·기관 정책 검토가 필요합니다. 앱은 다중 사용자 공유 DB를 지원하지 않으며 공용 폴더의 파일을 여러 PC가 동시에 수정하는 방식으로 쓰면 안 됩니다.

알림은 앱이 실행 중에만 동작합니다. 기본 닫기는 종료이며, 트레이 상주를 켜면 창을 숨겨도 점검합니다. 시작 시 최근 1분만 점검하고 절전 복귀 시에는 지난 24시간을 보충합니다. 알림 표시 요청과 실제 OS 수신은 구분하며, 실패가 보고되면 재시도할 수 있습니다. 지난 업무는 브리핑에도 남습니다.

- `npm test`: 37개 데이터·데스크톱 정책 테스트. 트레이 실패·종료 보호, 절전 복귀·알림 재시도·영구 중복 방지, 장기 반복·DST 경계를 포함합니다. 반복 일정 파생·월말/윤년/종료일 경계·오프라인 공휴일/대체공휴일 계산, 조직/근무 참조·중복·날짜·CSV·v2 원본 전환, 기존 자료 전환·보존, 순찰/업무 연결 무결성, 백업 왕복, 달력 원본 연계, 사전 알림, 브리핑 범위, DD↔DMS 정확도·경계·잘못된 입력·v0.2 좌표 호환성 검사.
