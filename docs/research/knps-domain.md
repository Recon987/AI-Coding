## 3. 단속 대상과 규모

- 2021~2025.8 적발: 취사 1,638건(최다), 흡연 547건 등 [확인] ([디지털타임스](https://www.dt.co.kr/article/12021323)).
- 과태료는 위반 유형·차수별로 다르다(예: 지정 장소 외 야영 1차 20만 원~3차 이상 50만 원) [확인] (위 파이낸셜뉴스 보도). 금액은 시행령으로 바뀌므로 **앱에 금액을 하드코딩하면 안 된다.**
- 비법정 탐방로 사고의 사망 비율 28.1%, 정규 탐방로 7.6% [확인] ([위키트리, 국회 자료 인용](https://www.wikitree.co.kr/articles/1158538)). 샛길 순찰·단속이 안전 업무와 직결된다.

## 4. 위치 표기

- 산악 구조 신고에는 **국가지점번호**(한글 2자 + 숫자 8자리, 2013 도입)가 112·119 공통으로 쓰인다 [확인] ([세계일보](https://m.thesegye.com/news/view/1065592203126049)). 국립공원도 번호판 설치 주체로 참여한다 [확인] (담양군 사례, 무등산국립공원).
- 공단 고유의 탐방로 위치표지(지점 번호 등) 체계와 명칭은 [가설] — 공개 자료로 확인하지 못했다.
- 현재 앱은 위도·경도(DD/DMS)만 지원한다. 국가지점번호는 격자 좌표계라 투영 변환이 필요하다. AGENTS.md는 투영 변환을 금지하지 않지만 "각도 표기 변환일 뿐"이라고 명시하므로, 도입하려면 **별도 과제와 정확도 검증**이 필요하다.

## 5. 기관이 이미 가진 시스템 (중복 주의)

- 대피소·야영장·생태탐방원 예약 시스템(카카오·올원뱅크 연동) [확인] ([데일리안](https://www.dailian.co.kr/news/view/1656210/)).
- 탐방 통제 정보 공개(공단 누리집, 국립공원 앱) [확인].
- ERP·전자결재·근태 등 내부 시스템 [가설: 존재는 확실하나 기능 범위 미확인]. 현재 앱의 `docs/erp-integration.md`도 ERP 열 구조를 미확인으로 기록함.

→ 이 앱이 이길 수 있는 곳은 **공식 시스템이 다루지 않는 개인의 현장 기록과, 그것을 공식 보고로 옮기는 수고를 줄이는 일**이다. 예약·통제 공지·근태를 다시 만드는 것은 가치가 낮다.

## 6. 사용자에게 확인할 질문

1. 이 앱의 1차 사용자는 누구인가? (본인 직무: 레인저 일반직 / 공무직 탐방안전·자원보전 / 행정 / 분소장) 한 직무를 먼저 정해야 기능을 좁힐 수 있다.
2. 현장에서 실제로 쓰는 **순찰일지·단속 대장·근무일지·시설 점검표** 서식(빈 양식이면 충분)을 받을 수 있는가?
3. 순찰 위치를 무엇으로 적는가? (탐방로 구간명 / 지점 번호 / 국가지점번호 / GPS)
4. 단속 기록은 어디까지 개인 PC에 남겨도 되는가? (위반자 인적사항은 개인정보·수사 자료 성격 — 암호화 전에는 넣으면 안 됨)
5. 특보 시 비상근무 단계와 편성 방식이 있는가? 근무표 화면에 반영할 필요가 있는가?
6. 사무소 PC에 개인 설치 프로그램을 허용하는가? (배포 경로 결정)
