# 추천 양식 초안 v1 — 사용자 피드백용

- 작성: Claude · 2026-10-16 · 과제 [TASK-FORMS-01](../tasks/TASK-FORMS-01.md)
- 사용자 결정: 실제 서식을 받는 대신 앱이 양식을 추천해 만들고 사용자가 피드백한다([knps-domain.md 7장](knps-domain.md#7-사용자-답변-2026-10-16)).
- TXT 머리말과 출력 화면에 **"추천 양식 · 공식 서식 아님"**을 표시한다. CSV는 후속 편집을 위한 열 머리글로 시작하며 안내 행을 삽입하지 않는다. 공단 로고·표장은 쓰지 않는다.
- 원칙: 앱에 이미 있는 기록에서 만든다(다시 입력하지 않음). 위반자 인적사항·과태료 금액은 넣지 않는다.

## 1. 순찰일지 — 구현됨 (v1)

기간 안의 순찰 기록을 시간 순서로 정리한다. 한 사람의 하루 일지로도, 여러 날 묶음으로도 쓸 수 있다.

| 순서 | 항목 | 앱 자료 | 비고 |
| ---: | --- | --- | --- |
| 1 | 순찰 일시 | `at` | `2026. 10. 15. 08:00` |
| 2 | 기록자 | `observer` | |
| 3 | 순찰 종류 | `kind` | 없으면 빈칸 |
| 4 | 담당구역 | `zone` | 없으면 빈칸 |
| 5 | 순찰 구간 | `route` | |
| 6 | 확인 등급 | `risk` | 일반 기록 / 확인 필요 / 우선 확인 |
| 7 | 확인 사항 | `findings` | |
| 8 | 현장 조치 | `action` | |
| 9 | 단속·확인 건 | `observations` | `흡연 2건(계도), 취사 1건(과태료 부과)` |
| 10 | 위치 | `coordinates` | 위도·경도(십진도) |
| 11 | 후속 업무 | 연결된 인수인계 | 제목과 상태(진행 중/완료) |

TXT 끝에 **요약**: 순찰 건수, 순찰 종류별 건수, 확인 등급별 건수.

## 2. 단속·계도 기록 — 구현됨 (v1)

단속·확인 건 한 줄에 한 건. 기간 안의 모든 순찰에서 모은다.

| 순서 | 항목 | 앱 자료 |
| ---: | --- | --- |
| 1 | 일시 | 순찰 `at` |
| 2 | 담당구역 | 순찰 `zone` |
| 3 | 순찰 구간 | 순찰 `route` |
| 4 | 기록자 | 순찰 `observer` |
| 5 | 유형 | `observations[].type` |
| 6 | 건수 | `count` |
| 7 | 조치 | 계도 / 과태료 부과 / 기타 조치 |
| 8 | 위도 · 9 경도 | 단속 건 `coordinates` (없으면 순찰 위치) |
| 10 | 메모 | `note` |

TXT 끝에 **유형별 합계**(건수·계도·과태료·기타) — 현장 순찰 화면의 집계와 같은 값.

## 3. 시설 점검표 — 초안만 (구현 전 피드백 필요)

지금 앱에는 시설 목록과 점검 항목 자료가 없다. 순찰 종류 "시설 점검"으로 기록할 수는 있지만 항목별 상태를 남길 곳이 없다. 아래 형태가 맞는지 확인받은 뒤 별도 카드로 구현한다.

| 순서 | 항목 | 예시 |
| ---: | --- | --- |
| 1 | 점검 일시·점검자 | |
| 2 | 시설명 | 탐방로 데크 3구간, 안전난간, 대피소 |
| 3 | 담당구역 | 3-2 |
| 4 | 점검 항목 | 고정 상태, 파손, 미끄럼, 안내판 가독성 |
| 5 | 상태 | 양호 / 보수 필요 / 사용 중지 |
| 6 | 조치 | 현장 조치 내용, 보수 요청 여부 |
| 7 | 다음 점검일 | 달력에 자동 표시 |

## 출력 형식

- **TXT**: 사람이 읽고 붙여 넣기 위한 형식. UTF-8(BOM 포함, 메모장 호환).
- **CSV**: 엑셀로 열어 편집·집계하기 위한 형식. UTF-8 BOM, 쉼표 구분, 모든 칸 큰따옴표. `= + - @`로 시작하는 값은 앞에 `'`를 붙여 엑셀 수식으로 실행되지 않게 한다.

## 사용자에게 확인할 것

1. 순찰일지 항목 순서·이름이 현장에서 쓰는 말과 맞는가? 빠진 항목(예: 날씨, 동행자, 차량)이 있는가?
2. 단속·계도 기록에 "과태료 부과"와 "고발·인계"를 구분해야 하는가? (지금은 계도 / 과태료 부과 / 기타 조치)
3. 시설 점검표의 상태 구분(양호 / 보수 필요 / 사용 중지)과 항목이 맞는가? 구현할까?
4. 출력은 TXT·CSV면 충분한가, 인쇄용(A4) 화면도 필요한가?
