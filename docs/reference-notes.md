# 참고 자료와 독립 구현 범위

사용자가 기후노트(https://gitlab.aigov.go.kr/whrhkdrh/climate-note)를 참고 사례로 제공했다. 업로드한 문서와 일부 Python 소스를 검토했으며 원격 저장소 전체를 실행하거나 검증한 것은 아니다.

현재 공원 업무 수첩의 구현은 기존 Electron/React 코드에서 발전시켰다. 기후노트의 Python 코드, Qt UI 구성요소, 아이콘, 이미지, 폰트, 이름, 문구, DB, 암호화 형식을 복사·번들하지 않았다. 기후노트 파일은 검토용 첨부 자료이며 이 저장소에 추가하지 않는다.

참고한 일반 원칙은 인터넷 없는 실행, 빠른 기록, 데이터 보존, 백업, 화면 잠금/알림의 수명 관리 필요성이다. 독자적인 기능 구조는 현장 순찰→후속 인계→마감→완료이며, 업무 브리핑/기록 목록/통합 월간 일정으로 구성했다. 기관 로고나 공인된 서비스 표장을 사용하지 않는다.

기후노트는 제공된 LICENSE 기준 GPL v3다. 향후 해당 코드·GPL 구성요소를 도입하면 이 기록과 라이선스·소스 제공 범위를 다시 검토해야 한다. 현재 메모는 법률 검토나 제3자 권리의 보증을 의미하지 않는다. 공통 기능 자체와 실제 코드·리소스 재사용은 구별해 기록한다.
