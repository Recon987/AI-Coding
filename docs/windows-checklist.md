# Windows 실기기 확인

자동 검증과 실제 기관 PC 확인을 구분한다. 이 목록은 통과 결과가 아니라 확인 절차다.

1. GitHub Windows 빌드에서 npm 잠금 설치·단위 테스트·실제 Electron 테스트·NSIS/portable 생성을 확인한다. 결과는 해당 Actions 실행 로그로 판정한다.
2. Windows 10/11 x64 테스트 PC에서 설치 경로 선택·실행·종료·재실행·제거 확인. portable EXE도 데이터 경로가 유지되는지 확인한다. 코드 서명은 미설정이며 배포 승인 절차를 별도로 마련한다.
3. 외부 인터넷을 끊고 메모, 전화, 순찰, 인계, 제출 업무, 달력과 검색을 사용한다. 순찰→인계 연결, 완료/미완료 전환, 순찰 삭제 시 인계 내용 유지, 일정 원본 수정 반영을 확인한다.
4. 가까운 시각의 일정 및 제출 업무를 등록해 Windows 알림을 확인한다. 집중 지원·알림 허용 설정을 점검한다. 앱을 켠 채 절전에 들어가 일정 시각을 지나 복귀하면 지난 24시간 미완료 알림이 보충되는지 확인한다. 반복 복귀·재실행에서 중복 요청이 없는지, 완료/미래/24시간 밖 항목은 제외되는지 확인한다. 실제 절전 중이나 앱 종료 중에는 표시되지 않는다.
5. v0.1/v0.2 원본을 복사한 시험 프로필에서 v3 전환 후 원본 백업과 메모 보존을 확인한다. 전체 백업의 취소·복원·잘못된 파일 거부·복원 전 자동 보관을 확인한다.
6. 브리핑 TXT에 선택 날짜의 기록과 기준일까지 마감한 현재 미완료 업무가 들어가는지 확인한다. 기관 양식의 공식 보고서가 아닌 개인 정리 자료다.
7. 100%/125%/150%/200% DPI, 960px 이상 창과 다중 모니터에서 입력·스크롤·날짜 선택·한글 파일 경로를 확인한다.
8. 실제 자료 반입 전 저장 암호화·기관 개인정보·배포 정책을 검토한다. 기본 검증은 가상 자료만 사용한다.

## 트레이 상주·종료 보호 (v0.6)

- 기본 꺼짐에서 X는 종료한다. 앱 안내의 트레이 상주를 켜면 X는 창만 숨기고 알림 점검을 유지한다.
- 트레이 아이콘(숨겨진 아이콘 영역 포함)의 클릭/열기, 앱 재실행, 알림 클릭으로 창이 다시 표시되는지 확인한다.
- 작성 중 창을 숨겼다 열어 입력 내용이 유지되는지 확인한다. 트레이 종료에서 기본 계속 작성을 선택하면 창과 초안이 유지되고, 변경을 버리고 종료를 선택할 때만 끝나야 한다.
- 상주 설정을 끈 뒤 X 종료, 재실행 후 설정 보존을 확인한다. Windows 시작 시 자동 실행은 제공하지 않는다.
- 트레이/설정 실패 메시지가 있으면 창을 유지하는지 확인한다. PC 설정과 알림 이력은 업무 JSON 백업/복원으로 교체되지 않는다.
