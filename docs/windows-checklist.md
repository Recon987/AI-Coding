# Windows 실기기 검증 (미실행)

1. 인터넷이 되는 Windows 10/11 x64 빌드 PC에서 Node.js 24 설치 후 `npm ci`, `npm test`, `npm run test:desktop` 실행.
2. `npm run package:win`으로 NSIS 설치 파일 생성. 현재 코드 서명 미설정이므로 배포 정책에 맞는 서명 절차를 별도 마련.
3. 깨끗한 테스트 PC에서 설치 경로 선택·실행·종료·재실행·제거 확인. 설치 파일은 아직 이 Linux 작업에서 생성하거나 검증하지 않음.
4. 외부 인터넷을 끊고 메모, 전화, 일정, 폴더 등록과 파일 저장을 확인. 앱 재실행 후 유지 확인.
5. 1분 뒤의 일정을 등록하여 Windows 알림 표시 확인. Windows 집중 지원·알림 허용 설정 확인. 종료·절전 중 알림은 현재 지원하지 않음.
6. 백업 내보내기, 취소, 복원, 잘못된 파일 거부, 복원 전 자동 보관 확인. 다른 PC에서 폴더 경로가 다르면 다시 등록.
7. 실제 기관 자료를 반입하기 전 개인정보·망 반입·암호화·배포 승인 정책 검토. 기본 테스트는 가상 자료만 사용.
