## 구현 메모
- 사이드바 `<nav aria-label="주 메뉴">`: 기본(업무 브리핑·월간 일정·인수인계·제출 기한·업무·전화 메모) / 모듈(켠 것만, 저장 순서) / 모듈 관리·바로가기·앱 안내. 메뉴 글자는 짧은 이름(`인수인계·기한`, `메모·전화`), 접근 이름은 전체 이름.
- 화면이 둘 이상인 도구는 제목 아래 `<nav class="page-switch" aria-label="<도구> 보기">`로 전환. 도구 메뉴를 다시 누르면 지금 보던 화면을 유지. Page ID·검색·브리핑·달력 링크는 그대로.
- 모듈 관리 서랍: 스위치(role=switch)·↑/↓ 버튼, 바꿀 때마다 바로 저장. 숨긴 모듈도 서랍 목록에 자리를 유지해 다시 켜면 원래 자리로 돌아온다. 저장 중·목록 끝·읽기 전용은 `aria-disabled`로 표시해 키보드 포커스를 잃지 않는다(맨 위로 옮긴 직후 포커스가 body로 빠지던 결함을 검사에서 찾아 고침). 읽기 전용이면 안내 문구, 저장 실패면 서랍 안에 오류를 보인다(페이지 오류 띠는 서랍에 가려지므로).
- 숨김 = 메뉴에서만 빠짐. 지금 보던 화면을 끄면 이동하지 않고 그 화면에 "메뉴에서 숨겨져 있습니다" 안내와 `모듈 관리 열기`를 보인다(편집 창은 모달이라 초안이 열린 채 서랍을 열 수 없음 → 초안 손실 없음). 검색·브리핑·달력에서 숨긴 모듈 기록을 열면 같은 안내.
- 저장 알림(고정 위치)을 DOM에서 보기 전환 앞으로 옮겼다: 상단 줄에서 Tab 한 번으로 알림에 닿는 기존 A11Y 동작 유지.
- 새 설치(사무소 자료 없음)는 사무소 현황이 꺼져 있어, 테스트는 `tests/nav.cjs`의 `goTo`가 필요하면 모듈 관리에서 켠다.
