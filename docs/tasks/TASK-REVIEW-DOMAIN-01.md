## 배경
현재 앱은 순찰→인계→제출 흐름 중심의 일반 업무 수첩이며, 공단 업무 도메인이 충분히 반영됐는지 검토된 적이 없다. 사용자도 "정말 쓸 만한 앱인지" 의문을 제기했다.

## 완료 조건
- [ ] 공개 자료(공단 누리집·경영공시·직무 소개·채용 직무기술서, 자연공원법 등 관련 법령) 기반 직무 분류와 직무별 일·주·계절 업무 목록. 출처 링크 필수
- [ ] 직무마다 "현재 앱으로 되는 것 / 우회해야 하는 것 / 안 되는 것" 표
- [ ] 계절성 업무(산불조심기간 입산통제, 하절기 집중호우·폭염, 동절기 결빙·적설 통제, 성수기 야영장·대피소) 반영 여부
- [ ] 근거가 공개 자료에 없는 업무 규칙은 "가설 — 사용자 확인 필요"로 분리하고 사용자에게 물을 질문 목록 작성
- [ ] `docs/research/knps-domain.md`와 `docs/reviews/<날짜>-domain.md`(review-lenses A, 점수와 발견 표)

## 범위 밖
코드 수정. 내부망·비공개 자료 접근. 공식 시스템 대체 주장.
