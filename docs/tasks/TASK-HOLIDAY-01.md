## 구현 내용·검증 요점
- 조사: docs/research/holidays.md(출처 포함). 관보 원문은 기관에서 최종 확인 필요.
- 내장 표(`shared/model.mjs`): 노동절(5/1)·제헌절(7/17) 2026년부터(`from`), 관공서 규정대로 주말·겹침 대체. `FIXED_HOLIDAYS`: 2025-01-27 임시공휴일, 2025-06-03 대통령선거일, 2026-06-03 지방선거일, 2028-04-12 국회의원선거일(대체 없음). `LUNAR_TABLE_YEARS`.
- **기존 오류 수정**: 같은 날 두 공휴일이 겹치면 대체공휴일을 하루 더 만들던 것(2025-05-07, 2028-10-06이 잘못 공휴일로 표시) → 겹친 날마다 (공휴일 수 − 1)일만.
- 사용자 공휴일: 선택 컬렉션 `customHolidays`(없으면 빈 목록, 기존 자료 그대로 열림). `holidaysForYear(year, custom)`, `holidayName(date, custom)`, `enforcementRange(date, custom)`, `briefing`이 사용. 같은 날이면 이름을 ' · '로 합치고 대체공휴일은 만들지 않음. `parseHolidayLines`: 붙여 넣기 반입, 한 줄이라도 틀리면 전부 거부, 이미 있는 날짜는 건너뜀.
- 화면: 자료 관리 → '공휴일 관리' 시트(직접 등록·붙여 넣기·삭제 확인), 달력 월·주·목록 보기 반영, 음력 표 범위 밖 해에 안내 문장. 외부 호출·새 IPC 없음.
- 자료 호환: `customHolidays`는 구버전이 잘못 읽지 않는 새 최상위 항목이라 `READER_VERSION`을 올리지 않았다. SCHEMA-01 이후 앱은 모르는 최상위 항목을 보존한다. SCHEMA-01 이전 앱(v0.8.0 이하)은 이 항목을 지우므로 기존과 같이 백업 안내.
