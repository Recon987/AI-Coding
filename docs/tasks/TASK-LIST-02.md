## 구현 내용
- `src/components/ListRow.tsx`: `RowAction.primary`(상태 변경 동작만 테두리 버튼), 그 밖은 글자 버튼, `tone: "danger"`는 빨간 글자. 전에는 '첫 번째 버튼'이 무조건 테두리였다. `ListHeader`에 `plain`(제목 열만) 추가, 머리줄을 `.row-list` 안에 둔다.
- `src/style.css`: `.row-list`를 2열 그리드(내용 | 동작), `.list-row`·`.list-header`는 subgrid로 동작 열 너비를 모든 행이 공유 → 버튼이 행 오른쪽 같은 줄에 세로로 맞춰진다. 1100px 이하는 전처럼 내용 아래에 버튼. `.record-actions`의 왼쪽 여백 계산 규칙 제거. `.row-list.plain`은 상태·담당 열을 숨긴다.
- 화면별: 순찰 '이 기록으로 새 순찰' → 화면 '새 순찰', 화면낭독기 이름 '이 기록으로 새 순찰 · 제목'(그대로). 탐방로 통제는 '오늘 해제'(상태 변경)를 '수정' 앞으로. 업무 메모의 '메모' 상태 열 제거. 머리줄 위치 이동(Controls·Patrols·Personal·Tasks).
- 측정(1280x800, 검토용 가상 자료): 순찰·인수인계·전화메모·업무 메모 행 67px(마지막 행 56px). 전에는 버튼 줄이 아래에 붙어 행이 더 높았다. 1000px에서는 버튼이 아래로 내려가 순찰 159px.
- 남은 아쉬움: 1280px 순찰 목록은 동작 열(약 280px) 때문에 제목 열이 좁아 제목이 말줄임된다(펼치면 전체). 필요하면 다음 주기에 담당 열 축소나 '수정'을 펼침 영역으로 옮기는 안을 검토.
